## MyUncleVision (computer-vision sister project)

[MyUncleVision](https://github.com/sandlerleon/MyUncleVision) reuses MyUncle's order and entropy definitions on lattices of image-patch embeddings (unsupervised anomaly discovery in images) and bridges back to this repository: `myuncle_vision.bridge` simulates any preset here and analyses the lattice states, and turns an analysed lattice into the initial state of a MyUncle Monte Carlo. This repository is vendored there unmodified.
